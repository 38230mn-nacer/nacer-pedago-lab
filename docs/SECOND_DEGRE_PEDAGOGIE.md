# Second degré interactif — intention pédagogique

Public : Première spécialité mathématiques.

Référence : BO n°14 du 2 avril 2026.

Réflexe visé :

**observer → identifier la question → choisir la forme → calculer → vérifier**

À éviter :

**trinôme → discriminant automatique**

- forme développée : coefficients, f(0), discriminant ;
- forme factorisée : racines, signe ;
- forme canonique : sommet, extremum, variations.
